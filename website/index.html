Parameterized by default

Compile returns SQL with placeholders plus ordered bindings. A diagnostic preview with substituted values is a separate, explicit call.

Six dialects, one API

SQL Server, PostgreSQL, MySQL, SQLite, Oracle and Firebird. Quoting, placeholders and paging follow the selected compiler.

Objects in, objects out

Map rows to classes with ToList, First or Single, write DTOs back, and execute through FireDAC or your own provider.

Up and running in three steps

  1. Add src to the Delphi search path. The core needs only the RTL; FireDAC is optional.
  2. Use two units: QueryBuilder4Delphi.Query.Core and QueryBuilder4Delphi.Query.
  3. Build, compile, execute. Pass the SQL and bindings to your data access layer, or call Execute with a provider.
